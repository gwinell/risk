# ZRISK — Crypto-Themed Landing Page

An experimental, single-page front-end exploring bold visual branding for a crypto-themed project.

**Scope:** a standalone [HTML page](index.html) with CSS animations, small JavaScript interactions and a [logo asset](logo.png). This repository is a website/design exercise; it does not contain a smart contract, custody software or an audited financial product.

## View locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in your browser, or open `index.html` directly. The page loads Google Fonts and contains outbound links to third-party crypto and social sites.

## Notes

This repository preserves a front-end experiment. Its existence does not verify or endorse any token or trading opportunity. Review external links independently.
